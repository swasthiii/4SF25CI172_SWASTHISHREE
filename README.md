# Spotify Data Analysis – Milestone 1

## Files
- `Spotify_Data_Analysis_Milestone1.ipynb` – analysis notebook.
- `spotify_data clean.csv` – synthetic Spotify-style practice dataset (8,582 rows, 15 columns).
- `README.md` – project instructions.
- `requirements.txt` – required Python packages.

## Dataset disclosure
The CSV is generated synthetic data for practising Python and Pandas. It is **not** an official Spotify export and does not contain real Spotify catalogue or listening records. If your assignment requires a specific dataset supplied by your college, replace this CSV with that original file.

## Run in VS Code
1. Extract this ZIP file.
2. Open the extracted folder in VS Code (**File → Open Folder**).
3. Open **Terminal → New Terminal**.
4. Run: `py -3.11 -m pip install -r requirements.txt`
5. Open `Spotify_Data_Analysis_Milestone1.ipynb`.
6. Select the Python 3.11 kernel.
7. Click **Run All**.

Keep the CSV and notebook in the same folder.
